## Beam Remote 1.7.0

**Update notifications for everyone.** When a new version is out you get a Windows notification (once per version), a banner on Home, an item in the tray menu, and anyone connected to the stream page sees a notice and can install it from Settings → About. Automatic updates still wait until nobody is connected.

**Embedding on by default.** Any website can show the stream page in a frame (signing in is still needed). Installs where it was off are switched on; a list of specific sites is kept.

**Find things faster.** A search box at the top of the app (Ctrl + K) finds any setting, button or help topic and takes you straight to it. The sidebar is grouped (Overview, Connect, Stream, App), Controllers have their own page, Embedding moved to Remote access, and the stream page's settings have their own search box.

Install: download `Beam-Remote-Setup-1.7.0.exe` below, or let the app update itself.
