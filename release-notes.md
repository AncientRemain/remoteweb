## Beam Remote 1.8.0

**Activation codes.** A new copy asks for an activation code the first time it starts. Each code works once, on one PC, and an activated copy never needs it again.

**Copies you already have stay free.** Every copy set up before this version keeps working without a code, for good.

**Seller tab.** Seller copies get a red Seller tab: make codes in one click, see which ones were used, and follow a step-by-step guide to selling in person. Every copy that existed before 1.8.0 is a seller copy.

**No code? Ask for access.** A new copy can ask with a name and a short message instead. Sellers see the request and can unlock it as paid or free, or decline it; the copy activates by itself a few seconds later.

**Open pages update themselves.** After an update, a stream page that's open reloads itself once into the new version and stays signed in.

Install: download `Beam-Remote-Setup-1.8.0.exe` below, or let the app update itself.
